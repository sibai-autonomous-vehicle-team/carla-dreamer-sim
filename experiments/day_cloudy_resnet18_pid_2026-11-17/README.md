# Cloudy-day CARLA distance CNN and 6 m gap PID

Run the commands in `commands.sh` from the Linux repository root. The experiment used the existing SSH session and the Linux archive at `dataset/combined_800/day_cloudy`. The merge manifest maps episodes 0–499 to the following collection and 500–799 to the full-range collection. The Mac path was unavailable from Linux, and the SSH peer refused a reverse connection. No dataset transfer was performed for this experiment. `dataset.sha256` fingerprints the input files actually used. `dataset_verification.json` records the archive checks.

Both source batches use the collector in `generate_dataset.py`. Each archived image and pose precedes its action. Gap and collision entries are recorded after the action. For an episode of length T, the CNN pairs images 1 through T−1 with gaps 0 through T−2, retaining the last stored image. Image 0 lacks its pre-action gap in the archive and gap T−1 describes the unsaved last successor. Archives do not contain camera capture frame IDs. The camera handler reads the latest callback buffer, so there can be additional visual lag relative to the simulator state.

The training script uses ImageNet-pretrained ResNet-18 with a single linear output, ImageNet RGB normalization at the archived 224 × 224 resolution, AdamW at 0.0001, and Huber loss. It selects the checkpoint with the lowest frame-weighted validation MAE across ten epochs. Seed 42 and the complete episode ID lists are in `split.json` and the checkpoint. Adjacent frames within one trajectory stay in one split. The split permits distinct trajectories from the same roads in each partition. CUDA operations used the installed backend defaults.

The live runs use Town03, the CloudyNoon preset with 45° sun altitude, 0.1 s simulation steps, and PID gains of 0.5, 0, and 0.5. The 6 m target uses the simulator's minimum Euclidean edge-to-edge clearance between the ego front and lead rear bounding-box faces. The same ground-truth steering and stock lead controller serve both modes. The lead controller follows its route and applies throttle below 2 m/s. Both modes start with five neutral longitudinal steps. The live CNN controller uses raw predictions.

A positive command produces throttle at command / 3. A negative command produces braking at −command / 3. Commands saturate at ±3. The environment ends on a strict true-gap crossing above 10 m, a route deviation above 5 m, collision, the lead planner's destination condition, or the environment time limit beyond 500 steps. The runner caps each run at 200 steps and also stops on any collision detected in the latest observation. A destination reached without a failure or reaching the runner step cap counts as completion.

The runner seeds Python and NumPy per episode, with the same seed for each pair. The reset temporarily advances CARLA asynchronously, and the camera buffer can lag the current simulation tick. Seed equality does not guarantee bitwise replay, and live gap error can include camera timing. The telemetry includes initial actor types, poses, velocities, and first PID input timing to check realized starts.

In each live CSV, true gap, raw CNN gap, and command are logged at decision time. The final successor gap is recorded separately. Tracking MAE averages absolute error from 6 m over post-step states, while minimum and maximum include the reset state. The alternate command is from a second PID running on the other gap source along the same realized trajectory. Only the applied command drives the vehicle. Alternate commands isolate input effects on that trajectory, and the paired rollouts capture the effect of the commands on later states.

## Results

The checkpoint from epoch 6 reached 0.689 m validation MAE. The 80 held-out episodes supplied 6,070 frames with 0.702 m MAE, 1.249 m RMSE, and −0.651 m mean signed error. Above 10 m, mean signed error was −4.591 m across 183 frames. Full bin counts and tail errors are in `test_metrics.json`.

Across five paired seeds, the ground-truth PID completed one route, exceeded the distance limit zero times, and ended for lane deviation four times. The CNN PID completed zero routes, exceeded the distance limit twice, and ended for lane deviation three times. There were no collisions. Seed 46 terminated for lane deviation during the first neutral step in both modes, so neither PID received a gap there. Both modes had matching logged vehicle types, starting positions and velocities, and initial clearance in all five pairs. Where a PID took control, first-control step and clearance also matched.

The CNN PID commanded braking in 38 decision steps where the ground-truth PID on that same trajectory would have commanded throttle. On the ground-truth runs, the diagnostic CNN PID commanded braking in 77 steps where the applied PID commanded throttle. On seed 42, the CNN estimated 7.70 m at a true gap of 9.78 m and commanded −0.23 while the diagnostic ground-truth PID commanded +2.53. The derivative term amplifies short-term changes in the CNN estimate. At the final action, the true gap was 10.00 m rounded and the CNN estimated 7.76 m. The true gap reached 10.10 m on the successor and triggered the cutoff. Seed 45 also ended at the distance cutoff with a 7.79 m CNN estimate and a 10.13 m successor true gap.

The mean of the five per-run tracking MAEs was 1.39 m for ground truth and 1.45 m for CNN. These means include trajectories of different lengths and the seed that ended before PID control, so compare the terminal reasons and per-seed traces alongside them. See `pid_summary.csv` for individual run metrics and `pid_summary.json` for starting-state checks.
